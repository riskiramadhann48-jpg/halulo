## SECTION B: STEP-BY-STEP TUTORIAL (00:40 – 06:30)

**[Visual Cue: Transition to Screen Recording. Browser opens to `github.com`.]**

> "First, let's open our web browser and go to **github.com**.  
> GitHub is a cloud-based platform that software engineers use for version control and project collaboration.  
> 
> If you don’t have an account yet, click the **'Sign up'** button in the top right corner. You only need to provide your email address, create a password, and verify your account.  
> 
> Since I already have an account, I will click **'Sign in'**, enter my credentials, and open my GitHub dashboard."

---

### Step 2: Create a New Repository (01:25 – 02:15)
**[Visual Cue: GitHub Dashboard. Cursor hovers over the green 'New' button.]**

> "Now that we are on our dashboard, our second step is to create a new repository. A repository is essentially a folder or storage space for all of our project files.  
> 
> Let's click the green **'New'** button on the left panel.  
> Under **'Repository name'**, I'll name it `riski-portfolio`.  
> Make sure the visibility is set to **'Public'** so anyone can visit our published website.  
> We can check **'Add a README file'** to initialize the repository, and then click **'Create repository'**.  
> 
> Great! Our online project repository is ready."

---

### Step 3: Create & Explain HTML and CSS Files (02:15 – 03:55)
**[Visual Cue: Switch screen to Code Editor (e.g. Visual Studio Code) showing `index.html` and `style.css`.]**

> "Next, let's look at our project code. To keep things clean, fast, and lightweight, we only need two essential files: `index.html` and `style.css`.  
> 
> First, let's examine `index.html`. It acts as the skeleton or structure of our webpage:  
> - At the top, we have our `<header>` with a navigation bar containing links to **About**, **Skills**, **Projects**, and **Contact**.  
> - Inside the `<main>` tag, we have our **Hero section**. It showcases my name, my aspiration to become a **Software Engineer** and **Data Scientist**, alongside a clean SVG developer avatar.  
> - Notice these call-to-action buttons here. They guide visitors directly to explore my work or contact me.  
> - Further down, we have the **About** section sharing my background, the **Skills** section highlighting tools like C++, Python, MySQL, and Figma, and my **Featured Projects**—including my C++ project *Manajemen Kos Digital* and my Figma mobile prototype for scholarship info.  
> - Finally, we have the **Contact** section with my direct email and phone number.  
> 
> Now, let’s switch to `style.css`. If HTML is the skeleton, CSS is the design and outfit:  
> - To make this look clean and modern, I used a pure **white background** for a minimalist feel.  
> - For our buttons and interactive accents, I chose a vibrant **ocean blue color** (`#0077b6`). Ocean blue represents clarity, technology, and trust.  
> - Everything is responsive, meaning it adapts smoothly whether viewed on a laptop or a smartphone."

---

### Step 4: Upload Your Files to GitHub (03:55 – 04:45)
**[Visual Cue: Switch back to GitHub repository in browser. Drag and drop or click 'Add file' -> 'Upload files'.]**

> "Now, let's bring our local code into GitHub.  
> Back in our repository page, click **'Add file'** and choose **'Upload files'**.  
> 
> We will select both `index.html` and `style.css` and drag them directly into the upload area.  
> 
> **Important tip:** Ensure that `index.html` is spelled in all lowercase and placed directly in the **root directory** of your repository. GitHub Pages looks for `index.html` as the default entry point.  
> 
> In the commit message box at the bottom, type a descriptive note such as:  
> `'Initial commit: add portfolio landing page HTML and CSS'`.  
> Then click the green button that says **'Commit changes'**.  
> Both files are now safely uploaded."

---

### Step 5: Publish Website Using GitHub Pages (04:45 – 05:35)
**[Visual Cue: Click 'Settings' tab -> Click 'Pages' in left sidebar -> Show branch selection.]**

> "Now comes the most exciting part: hosting our website live for free using GitHub Pages!  
> 
> 1. Click on the **'Settings'** tab located at the top menu bar of your repository.  
> 2. On the left sidebar, scroll down to the **'Code and automation'** section and click on **'Pages'**.  
> 3. Under **'Build and deployment'**, check the Source dropdown and confirm it says **'Deploy from a branch'**.  
> 4. Under **'Branch'**, select the `main` branch, keep the folder as `/ (root)`, and click **'Save'**.  
> 
> Now GitHub will automatically build and deploy our landing page. It usually takes about 30 to 60 seconds to process."

---
