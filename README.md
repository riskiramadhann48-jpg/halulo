## 📖 How to Deploy to GitHub Pages
1. Fork or clone this repository.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**.
5. Your website will be live at `https://<your-username>.github.io/<repo-name>/`.
